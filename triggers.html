How 67's trigger system will work

WHEN choose an event or condition

IF optionally add a threshold or filter

THEN choose a notification channel

Initial channels can be browser notifications and in-app notifications. Telegram, email, push and other channels can be added after the server-side trigger worker is live.

🔐 Private chats — planned securely

67 will use end-to-end encryption for private messages only when the complete key-management, device recovery, multi-device and message-delivery design is implemented and tested. We will not label ordinary server-stored chat as “end-to-end encrypted”.
